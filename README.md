# Studying Effectively

Studying Effectively is a web app made to help students stay focused while studying. The app uses a study timer along with camera-based attention tracking. If the user gets distracted or looks away for too long, the timer can pause until they return to studying.

## Planned Features

- Study timer
- Camera-based attention tracking
- Automatic timer pausing
- Different study modes
- Study goals
- Study session and interruption tracking

## Technology

We plan to build the project as a web application and use the user's webcam for attention tracking. The project will use facial detection/computer vision to help determine when the user is focused or looking away.
